quickstart

you'll need node.js, a discord bot token, and a webhook url

clone the repo and install dependencies.

bash 
$git clone https://github.com/technoz3n/ultragreed.git
$cd ultragreed
$npm install

create a .env file with your keys.

.env 
# .env
BOT_TOKEN=your_discord_bot_token_here
WEBHOOK_URL=your_discord_webhook_url_here

start in development or production mode.

bash 
# development
$npm run dev

# production
$npm run start
