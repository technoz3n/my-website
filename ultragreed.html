a lightweight, real-time discord quest tracking bot that monitors public API endpoints and dispatches formatted webhook alerts directly to your server.

safe polling zero internal user-api scraping, preventing token blocks or account flags.

state isolation ignores state configuration tracking files to avoid nodemon restart loops.

terminal quickstart
1 clone & install 
git clone https://github.com/technoz3n/ultragreed.git
cd ultragreed
npm install
2 configure environment (.env) 
BOT_TOKEN=your_discord_bot_token_here
WEBHOOK_URL=your_discord_webhook_url_here
3 launch bot 
# development mode
npm run dev

# production mode
npm run start
